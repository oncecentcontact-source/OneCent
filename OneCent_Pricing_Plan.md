# OneCent - Pricing Plan

## Pricing Model Overview

OneCent uses a transparent, usage-based pricing model designed to scale with your platform's growth. Our pricing consists of two components:

1. **One-Time Setup Fee** - Initial integration and account configuration
2. **Per-Request API Fee** - Pay only for what you use (100 MMK per API request)

### 📊 API Request Pricing

**100 MMK per API request**

#### What Counts as an API Request?

Each query to verify a transaction counts as one API request:

✅ **Counted as 1 Request:**
- Query transaction history by respective payment (Kpay or Wave Pay)


❌ **Not Counted:**
- Authentication/token refresh
- System health checks

## Frequently Asked Questions

### Q: Is there a minimum monthly commitment?
**A:** No, you only pay for the API requests you actually use. No minimum usage required.

### Q: What happens if I exceed my prepaid package?
**A:** Additional requests are billed at the standard rate (100 MMK/request) at month-end.

### Q: Can I upgrade/downgrade my package?
**A:** Yes, you can change packages anytime. Setup fee difference applies for upgrades.

### Q: What if the API is down?
**A:** We maintain 99.9% uptime. Enterprise customers receive SLA credits for any downtime.

### Q: How do I track my API usage?
**A:** Real-time usage dashboard included with all plans. Monthly reports sent via email.

### Q: Can I get a custom pricing plan?
**A:** Yes! Contact us for custom pricing for high-volume platforms (500,000+ requests/month).

### Q: Is there a trial period?
**A:** Yes, we offer a 7-day free trial with up to 500 API requests to test the service.

### Q: What payment methods do you accept?
**A:** Bank transfer, KPay, and Wave Pay. Invoices provided for all transactions.
